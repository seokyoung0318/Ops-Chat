# Runbook: 배포 직후 장애(Bad Deploy) 롤백 절차

증상: 새 버전 배포 직후 오류율이 급증한다, 특정 버전 배포 이후부터 문제가 시작됐다, 기능이 갑자기 동작하지 않는다.

1. 장애 시작 시각과 직전 배포 시각을 비교해 배포 연관성을 확인한다.
2. 오류율이 임계치를 넘으면 이전 안정 버전으로 즉시 롤백한다.
3. 카나리/블루그린 배포였다면 신규 버전으로 가는 트래픽을 0%로 되돌린다.
4. 롤백 후 오류율과 응답 시간이 정상 범위로 돌아왔는지 확인한다.
5. 정상화 후 실패한 배포의 변경 내역을 분석하고 배포 전 검증 항목을 보강한다.
