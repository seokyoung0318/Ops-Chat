# Runbook: 로그인/인증 실패 급증(Authentication Failure) 대응 절차

증상: 로그인이 안 된다, 인증 오류(401/403)가 급증한다, 토큰 발급 또는 갱신이 실패한다.

1. 인증 서버의 오류율과 실패 사유(비밀번호 오류, 토큰 만료, 서명 검증 실패)를 구분한다.
2. 인증 서비스가 의존하는 사용자 DB, 세션 저장소(캐시)의 상태를 확인한다.
3. 토큰 서명 키 교체나 설정 변경이 최근에 있었는지 확인하고, 문제가 있으면 이전 설정으로 되돌린다.
4. 특정 IP에서 실패가 몰려 있으면 무차별 대입 공격을 의심하고 해당 IP를 차단한다.
5. 정상화 후 인증 실패율 알림 임계치와 계정 잠금 정책을 점검한다.
