# Runbook: SSL 인증서 만료(SSL Certificate Expiry) 대응 절차

증상: HTTPS 접속 시 "인증서가 유효하지 않음" 경고, 인증서 만료 알림, 외부 API 호출이 TLS 오류로 실패한다.

1. 만료 대상 도메인과 인증서 만료 일시를 확인한다.
2. 자동 갱신(예: cert-manager, ACME) 실패 로그를 확인하고 수동 갱신을 시도한다.
3. 새 인증서를 로드밸런서/게이트웨이에 적용하고 서비스를 점진적으로 재로드한다.
4. 외부에서 인증서 체인과 만료일이 갱신되었는지 확인한다.
5. 정상화 후 만료 임박 알림(30일/7일 전)이 동작하는지 점검하고 재발 방지 항목을 등록한다.
